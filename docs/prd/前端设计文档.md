# DeciGro 前端设计规范 (DDS) v3.0

**核心理念：理性 (Rationality) | 信赖 (Trust) | 掌控 (Control)**

## 1. 设计哲学 (Design Philosophy)

1. **金融级清晰度 (Financial Clarity)**:
* 摒弃深色模式的压抑和纯白模式的刺眼。
* **底色**: 使用 **极淡的蓝灰色** (`#F8F9FA`)，模拟高级纸张的质感，长时间注视不疲劳。
* **数据**: 所有的金额、率、量，必须使用 **等宽字体**，且对比度极高。


2. **结构化智能 (Structured Intelligence)**:
* AI 不是“聊天机器人”，而是“业务副驾驶”。
* AI 的输出（文案、报表）不应淹没在对话流中，而是通过 **“Artifacts（工件面板）”** 独立呈现。


3. **Google Blue 核心 (Trust Anchor)**:
* `#4285F4` 是系统的灵魂，代表连接与执行。它只出现在**可交互**的关键路径上（按钮、链接、选中态），而非滥用。

## 2. 视觉基础 (Visual Foundation)

### 2.1 色彩体系 (Color System)

| 语义 | 色值 (Hex) | Tailwind 类名 | 应用场景 |
| --- | --- | --- | --- |
| **品牌主色** | **`#4285F4`** | `bg-blue-500` | 核心操作按钮 (Primary Button)、Logo、高亮文本 |
| **品牌深色** | `#174EA6` | `bg-blue-800` | **侧边栏背景** (构建稳重的左侧锚点) |
| **品牌浅色** | `#E8F0FE` | `bg-blue-50` | AI 对话气泡、选中项背景、Hover 态 |
| **页面底色** | `#F8F9FA` | `bg-slate-50` | 全局背景，护眼灰白 |
| **卡片背景** | `#FFFFFF` | `bg-white` | 内容容器，叠加轻微投影 |
| **增长/收益** | `#34A853` | `text-green-600` | **金钱相关**（如涨幅、ROI、成交额） |
| **风险/阻断** | `#EA4335` | `text-red-600` | 亏损、异常、错误 |
| **AI 魔法** | Gradient | `bg-gradient-to-r` | 仅用于 AI 生成按钮或思考状态 (Blue to Violet) |
| **主文本** | `#202124` | `text-gray-900` | 标题、表格正文 |
| **次文本** | `#5F6368` | `text-gray-500` | 标签、辅助说明 |

### 2.2 排版 (Typography)

金融系统的核心在于数字的易读性。

* **UI 字体**: `Inter`, `Roboto`, `PingFang SC` (清晰、通用)。
* **数据字体 (核心)**: **`JetBrains Mono`**。
* *强制规则*: 凡是涉及 **金额 (¥, $)**、**百分比 (%)**、**ID**、**代码块**，必须使用此字体。
* *示例*: `<span class="font-mono font-bold text-gray-900">¥ 1,245,000.00</span>`



### 2.3 质感与层级 (Material & Elevation)

* **卡片风格**: 无边框，使用 **弥散投影** 制造悬浮感。
* `shadow-sm`: `0 1px 2px 0 rgba(0, 0, 0, 0.05)` (默认状态)
* `shadow-md`: `0 4px 6px -1px rgba(0, 0, 0, 0.1)` (Hover 状态，轻微上浮)


* **圆角**: 统一 `rounded-lg` (8px-10px)，既不锐利也不过于圆润，保持商务感。

## 3. 布局架构 (Layout Architecture)

### 3.1 框架结构 (App Shell)

采用经典的 **“深蓝侧栏 + 浅灰画布”** 结构，这是企业级 SaaS 最稳健的形态。

* **Sidebar (左侧, 240px)**:
* 背景: `#174EA6` (深蓝)。
* Logo: 白色，位于顶部居中。
* 导航项: 白色文字。选中时，背景变为 `#4285F4` (主色) + 右侧出现光标指示条。


* **Header (顶部, 64px)**:
* 背景: 透明或纯白 (带下划线)。
* 内容: 面包屑导航 (如: `首页 / 营销决策 / 双11 方案`) + 用户头像。


* **Main (内容区)**:
* Padding: `p-6` (24px)。
* 布局: **Bento Grid** (CSS Grid)。



### 3.2 Bento Grid 规范

内容区划分为整齐的网格，像便当盒一样规整。

* **间距**: `gap-5` (20px)。
* **响应式**:
* `lg`: 3 列 (适合宽屏看报表)。
* `md`: 2 列。
* `sm`: 1 列。

## 4. 核心业务组件 (Business Components)

### 4.1 智能决策工作台 (DeciGro Workbench)

这是用户与 Python AI 交互的核心区域。

* **布局**: 分为左右两栏 (Split View)。
* **左侧 (Chat Stream)**: 对话流。
* User: 纯白气泡，灰色边框。
* AI: **浅蓝气泡 (`#E8F0FE`)**，文字深蓝。**打字机效果**速度要快 (30ms/char)，光标为蓝色竖线。
* *状态*: 当 AI 思考时，底部出现一行小字 `Thinking... [调用工具:查询销量]`，伴随蓝色呼吸点。


* **右侧 (Artifacts Panel)**: **结果预览区**。
* 当 AI 生成“营销文案”或“趋势图表”时，不在左侧刷屏，而是右侧弹出一张**白色卡片**。
* 卡片顶部有操作栏：`Copy`, `Save to Java`, `Edit`。
* *目的*: 让决策者可以一边聊天，一边盯着生成的结果进行微调。





### 4.2 数据概览卡片 (Insight Card)

用于展示 Java 后端统计的 KPI。

* **结构**:
* 标题: `text-sm text-gray-500` (如 "Total Revenue")。
* 数值: `text-3xl font-mono font-bold text-gray-900` (如 "¥ 42,000")。
* 趋势:
* 涨: `text-green-600 bg-green-50` (胶囊样式) + `↑ 12%`。
* 跌: `text-red-600 bg-red-50` (胶囊样式) + `↓ 5%`。


* 微型图: 底部附带一个淡蓝色的 Sparkline (迷你折线图)，展示近7天趋势。



### 4.3 任务状态监控 (Task Monitor)

用于监控 Java 爬虫和长任务。

* **表格设计**:
* 表头: 极简，无背景，仅深灰文字。
* 行: 纯白背景，底边框 `border-gray-100`。


* **状态徽章 (Status Badge)**:
* 使用 **"Dot + Text"** 风格，比纯色块更精致。
* Running: 🔵 (Blue Dot) `Processing`
* Success: 🟢 (Green Dot) `Completed`
* Failed: 🔴 (Red Dot) `Failed`
* Pending: ⚪ (Gray Dot) `Queued`

## 5. 交互与动效 (Interaction)

为了体现“智能感”，动效必须流畅但不花哨。

1. **Skeleton Loading (骨架屏)**:
* 数据加载时，不要用转圈圈。使用灰色的骨架屏，带有从左向右的 **Shimmer (微光扫过)** 动画。


2. **Stream Typing (流式输出)**:
* AI 输出时，内容高度会自动撑开。
* 只要内容还在生成，光标就保持闪烁。


3. **Hover Lift (悬停上浮)**:
* 鼠标经过 Bento 卡片时，卡片并在 0.2s 内向上浮动 2px，阴影加深。这给用户一种“可操控”的心理暗示。

## 6. 技术落地配置 (Tailwind CSS)

将以下配置复制到 `tailwind.config.js`，即可直接复用上述规范。

```javascript
module.exports = {
  theme: {
    extend: {
      colors: {
        brand: {
          50: '#E8F0FE',  // AI Bubble / Highlight
          100: '#D2E3FC',
          500: '#4285F4', // Google Blue (Primary)
          600: '#1A73E8', // Hover
          700: '#1967D2', // Sidebar
          900: '#174EA6', // Sidebar Active
        },
        growth: '#34A853', // Financial Positive
        risk: '#EA4335',   // Financial Negative
      },
      fontFamily: {
        sans: ['Inter', 'PingFang SC', 'sans-serif'],
        mono: ['JetBrains Mono', 'Roboto Mono', 'monospace'], // 核心数据字体
      },
      boxShadow: {
        'bento': '0 1px 3px 0 rgba(0, 0, 0, 0.1), 0 1px 2px 0 rgba(0, 0, 0, 0.06)',
        'bento-hover': '0 10px 15px -3px rgba(0, 0, 0, 0.1), 0 4px 6px -2px rgba(0, 0, 0, 0.05)',
      },
      animation: {
        'cursor-blink': 'blink 1s step-end infinite',
      },
      keyframes: {
        blink: {
          '0%, 100%': { opacity: '1' },
          '50%': { opacity: '0' },
        }
      }
    },
  },
}

```

## 7. 典型页面：决策主屏 (User Story)

想象一下：

> 你打开 **DeciGro**，左侧深蓝色的导航栏给人一种极其稳固的感觉。
> 页面正中央，是一个宽敞的 **Input 框**，你输入：“*复盘上周 A 股 ETF 资金流向，并生成针对高净值客户的营销话术。*”
> 屏幕没有剧烈闪烁，而是在输入框下方，平滑地推入一个淡蓝色的气泡。
> **“Received. Analyzing market data...”**
> 2秒后，右侧空白区域自动滑入一张 **Analysis Artifact (分析工件)** 卡片。
> 上半部分是 ECharts 渲染的资金流向柱状图（蓝绿红配色，清晰锐利），下半部分是生成的 3 条营销文案。
> 文案中的关键数据（如 `+12.5%`）被自动高亮为绿色，且使用了 JetBrains Mono 字体，显得格外专业。
> 你点击文案右上角的 **蓝色按钮 "Approve & Send"**，卡片收起，左侧侧边栏的“任务队列”图标处弹出一个绿色的小圆点，提示任务已下发 Java 后端执行。
